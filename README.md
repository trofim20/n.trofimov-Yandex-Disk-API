# Автотесты REST API Яндекс.Диска

## Описание проекта

Проект содержит пример автотестов REST API сервиса [Яндекс.Диск](https://yandex.ru/dev/disk/rest/) на Java
Тесты работают с API Яндекс.Диска через `https://cloud-api.yandex.net` и проверяют основные операции с файлами: загрузку, получение информации о ресурсе, перемещение-переименование, удаление в корзину, восстановление и безвозвратное удаление
Для запуска используйте отдельный тестовый аккаунт Яндекса

## Подготовка перед запуском

Перед запуском проекта необходимо:

1. Заполнить токен доступа в файле `testData.json`:

```json
{
  "testData": {
    "accessToken": "",
    "apiUrl": "https://cloud-api.yandex.net/v1/disk"
  }
}
```


### API-классы

- `BaseApi` - базовый класс для отправки HTTP-запросов, логирования и преобразования ответов в модели
- `YandexDiskApi` - класс для работы с эндпоинтами Яндекс.Диска: загрузка файлов, получение информации о ресурсах, перемещение, удаление в корзину/безвозвратно, восстановление из корзины, получение списка файлов в корзине
- `ApiResponse<T>` - обёртка для хранения статус-кода, тела ответа и типа контента

### Модели данных
- `YandexDiskFileData` - модель ресурса Яндекс.Диска (имя, путь, тип, размер, дата создания/изменения)
- `TestData` - модель тестовых данных из JSON-конфига (логин, пароль, токен, имя файла)

### Утилиты
- `FileUtils` - создание локального текстового файла, получение локального пути к файлу
- `SettingUtils` - загрузка тестовых данных из JSON-файлов
- `ApiEndpoints` - константы эндпоинтов API Яндекс.Диска
